# Studio JL Beauty&Co.

Site estático de uma página para apresentar os serviços do Studio JL Beauty&Co. e facilitar agendamentos pelo WhatsApp.

## Conteúdo

- `index.html`: página completa, com navegação responsiva Bootstrap Offcanvas, galeria, mapa, dados estruturados e links de agendamento.
- `images/`: dez imagens de publicações públicas do Instagram do Studio JL; cada item da galeria leva à publicação original.

Não há backend, autenticação ou banco de dados. Para atualizar os dados do negócio, edite `index.html`.
